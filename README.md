# DesktopLayoutSwitcher

这个小工具用于保存和恢复两类桌面布局：桌面图标位置、当前已打开应用窗口的位置。

使用方式：

1. 双击 `桌面布局切换工具.lnk`，打开图形界面；备用入口是 `启动桌面布局工具.cmd`。
2. 整理好当前桌面后，在“配置名”里输入名称，例如 `工位24寸`、`家里16寸`、`会议投屏`。
3. 点“保存当前布局”，这个名称会出现在“已保存配置”下拉框里。
4. 后续从“已保存配置”里选择名称，点“恢复所选配置”。

说明：

- `profiles` 目录会自动生成，里面是每个布局配置的 JSON 文件。
- `刷新列表` 只会重新读取显示器信息和已保存配置列表，不会改变当前桌面。
- 恢复窗口位置时只移动当前已经打开的窗口，不自动启动程序。
- 桌面开启“自动排列图标”时，Explorer 会重新接管图标位置，恢复效果会被覆盖。
- 命令行仍可使用：`powershell.exe -ExecutionPolicy Bypass -File D:\DesktopLayoutSwitcher\DesktopLayoutSwitcher.ps1 -Action Save -Profile 工位24寸`。
